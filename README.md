# exp3

Flutter experiment 3 - a product finder app that filters a list of items as you type.

## Use

```
flutter pub add exp3
```

```dart
import 'package:exp3/exp3.dart';

runApp(const SearchApp());
```


## Run in VS Code
1. Open this folder in VS Code (File > Open Folder).
2. Open a terminal and run:
   flutter pub get
3. Pick a device (Android phone, emulator, Chrome) from the bottom-right corner.
4. Press F5 or run: flutter run
